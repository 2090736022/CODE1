# CODE1：A股量价选股与量化研究

本仓库用于管理个人开发的 A 股量化研究程序，涵盖量价选股、历史回测、分钟与分时行情分析、买卖点识别、股票池管理及机器学习预测等功能。

项目最初以全自动交易为目标。受交易接口、历史数据成本和个人计算资源等条件限制，目前主要用于策略研究与辅助人工决策，尚未接入完整的券商自动下单流程。

策略会根据市场风格变化持续调整，通常每隔 3～6 个月研究或更新一套策略。仓库包含正在使用的策略、历史版本和实验脚本，各模块的成熟度并不相同。

## 一、数据来源与缓存

- **日线与基础数据**：主要通过 Tushare 获取，包含价格、成交量、换手率及市值等字段。
- **分钟与分时行情**：接入腾讯、新浪及东方财富相关接口，用于分钟量价信号和盘中监控。免费接口的历史范围有限，可获取日期以实际返回结果为准。
- **本地行情缓存**：`download.py` 按股票保存日 K，按日期保存 `daily_basic`，供选股和回测复用，减少重复请求。
- **分钟数据处理**：`minute_data.py` 提供时间窗口截取、成交量单位统一、累计成交量处理、数据完整性检查和按日缓存。
- **历史数据验证**：仓库另有历史分钟数据来源探测及样本审计脚本，主要用于检查数据可获取性、字段和样本质量，不代表所有来源均已稳定接入。

常用日线缓存目录为 `model_artifacts/download_daily/`。机器学习模块还使用独立的面板与特征缓存目录，两类缓存并非完全共用。

## 二、主要量价选股策略

### 1. lianghua1_search_botton.py：上涨趋势中的调整后启动

这是本人使用较多的一套策略，主要捕捉中长期趋势向上、经历短期调整后重新启动的股票。策略结合均线方向、MACD、成交量及历史涨停特征等条件，识别潜在的再次启动信号。

已配套开发近一年回测程序，报告目录为 `model_artifacts/botton_year_backtest/`。

### 2. lianghua1_search_turn.py：调整后的向上反转

该策略与 botton 策略有部分共同条件，但更侧重调整后量价关系的反转，结合前后交易日的价格、成交量、均线及 MACD 状态筛选候选股票。

回测报告目录为 `model_artifacts/turn_year_backtest/`。

### 3. lianghua1_search_test.py：强势股接力与二波机会

这是一套风险较高的超短线策略，研究具有连续涨停历史的强势股票在调整后继续走强、形成第二波上涨的机会。当前包含两个独立量价分支，回测明细会标明信号来源。

回测报告目录为 `model_artifacts/test_year_backtest/`。

### 4. chaoduan_1.py：日线筛选与分钟级放量异动

在趋势机会减少、日线策略信号稀疏的阶段，进一步尝试通过分钟量价变化捕捉尚未明显拉升、但已出现放量异动的股票。

该程序先进行日线与基础条件筛选，再检查观察日的分钟信号。由于缺少长期历史分钟 K 线数据，目前尚未完成长期回测。

### 补充策略与历史版本

- `lianghua1_search_iland.py`：研究低开调整后，高开、放量并转强的量价反转变体，同时结合均线、MACD 和历史涨停条件。代码中的 `island_reversal` 不等同于已经严格验证的经典岛形反转形态，当前未配套独立年度回测入口。
- `lianghua1_search.py`：日常主流程引用的基础选股版本。
- `chaoduan.py`：分钟信号筛选的基础实现，也是 `chaoduan_1.py` 复用部分功能的模块。

## 三、策略回测与报告

### 日线规则策略回测

`botton_year_backtest.py`、`test_year_backtest.py`、`turn_year_backtest.py` 分别提供三套策略的近一年回测，直接读取本地缓存，输出：

- 全部信号、完整收益样本和买卖价格日期；
- 日度与月度汇总、收益分布及最佳和最差样本；
- 数据覆盖、缺失记录及参数审计；
- 可通过浏览器查看的 HTML 报告和 CSV 明细。

回测沿用 `monthly_strategy_backtest.py` 的理论最佳收益口径：在信号日之后的十根日 K 中，选择某日开盘价买入，再选择严格更晚日期的收盘价卖出，取最高收益。

```text
最佳收益率 = max（后续卖出收盘价 ÷ 买入开盘价 − 1）× 100%
```

该指标描述信号后的事后最佳价格空间，不是固定规则的实际成交收益，也不是账户年度收益。当前未扣手续费和滑点，未模拟资金、仓位及涨跌停成交。

### HMM 月度滚动核验

`hmm_year_backtest.py` 默认在近一年内每月抽取一个交易日，为每只股票仅使用当时及以前的历史数据重新训练，核验下一市场交易日的预测。输出方向准确率、收益预测误差、参考基线及两种前十名排名的表现，并支持断点续跑。

其评估目标是次日预测能力，与上述日线策略的十日理论最佳收益口径不同。全池运行需要训练大量独立模型，计算时间较长。

## 四、分时强弱评分与候选股排名

这是独立于上述选股条件的盘中量价分析工具：

- `fenshi_strength.py`：从分钟 K 线提取上涨与下跌分钟成交量占比、近期量价动能、集中放量及后续价格反应、VWAP 偏离和上影线等特征，生成分时强弱规则评分。
- `rank_fenshi_strength.py`：结合本地日 K 涨幅条件扫描股票池，对符合条件股票计算分时评分，输出排名和明细。
- `train_fenshi_market_model.py`：汇总跨股票的分钟特征，配合日线及基础数据构造样本，训练随机森林分类模型。

分时强弱模块也保留了单股模型训练和模型评分函数，但当前 `calculate_strength` 的最终分数仍采用规则评分，没有实际融合模型分数。随机森林部分属于实验性研究，不应视为已完成验证的盘中预测策略。

## 五、日常流程与记录管理

- `main.py`：通过配置开关组织基础选股、结果汇总、买点、卖点和股票池清理流程。它引用的是基础 `lianghua1_search.py`，并非自动运行本仓库所有策略。
- `store.py`：汇总筛选结果、去重并生成候选股票池。
- `lianghua1_buy.py`：包含历史买点判断、当前分时数据读取及买点记录逻辑。
- `lianghua1_sell.py`：按交易日顺序判断放量下跌、缩量涨停次日、低开、长上影及反弹量能等卖出或买点更新条件，维护持仓与卖出记录。
- `lianghua1_delete.py`：根据候选股票未触发买点的等待时间、价格与均线关系等规则清理股票池，并保留删除记录。

这些模块主要维护研究和信号记录，不向券商发送真实订单。部分模块仍需接口联调；例如买点脚本引用的分时函数与当前 `fenshi.py` 的接口需要进一步核对，股票池删除规则中的 30 分钟 MA120 也使用日线 MA15 近似。

## 六、行情监控、邮件提醒与桌面显示

- `fenshi.py`：获取分钟行情，并按上一交易日收盘价计算涨跌幅。
- `sent_fenshi.py`、`sent_shangzheng.py`：轮询配置标的的行情，在价格相对上次通知基准变化达到阈值时发送邮件。
- `sent_fenshi_test.py`：将行情轮询、邮件提醒与桌面悬浮显示结合，通过后台线程和消息队列更新界面。
- `floating_window.py`：提供置顶悬浮窗口的独立界面示例。

现有邮件脚本主要是价格波动提醒，不等同于已经接入全部策略买卖点的通知系统。

## 七、机器学习与统计模型研究

曾尝试 Qlib 相关机器学习选股研究，受模型调优效果和个人计算资源限制，目前仍处于探索阶段。以下为仓库内实际包含的独立模型与实验程序。

### LightGBM 短期预测

`model.py` 按基准日市值筛选股票池，排除 ST，保留 MA120 不下降的历史样本，构造价格、成交量、换手率等 75 个特征。

通过一个分类模型和三个分位数回归模型，预测未来三个交易日最高价超过当日收盘价 1.5% 的概率，以及未来五个交易日最高价的上涨空间，再综合打分排序，保存模型、评估指标和结果。

`predict.py` 提供已保存模型的推理入口，支持指定股票、指定日期，刷新或补齐行情缓存，筛选候选样本并输出排名及后续价格空间统计。指定历史日期进行推理，并不自动保证模型本身是在该日期以前训练，不能直接视为严格的样本外回测。

当前模型的数据结束日期与验证、测试日期配置需要保持一致，标签观察窗口和时序验证也仍需完善。

### 趋势与拐点模型实验

`model2.py` 探索 LightGBM 与 HMM、GARCH、PELT 变点检测、DBSCAN 聚类的组合，预测未来趋势斜率和向上拐点，并尝试过滤震荡或异常样本。

当前仍存在评估排序对齐和部分特征的时序处理问题，属于研究版本，已有指标不能直接作为可靠的样本外效果证明。

### HMM 个股状态分析

`hmm.py` 获取近五年日 K，以收益率、振幅和成交量变化训练三状态隐马尔可夫模型，识别个股当前状态，估计下一交易日进入偏上涨状态的概率及预期收益，输出排名并保存 CSV。

其中，进入历史平均收益为正状态的概率，不直接等于实际收涨概率。配套回测入口为 `hmm_year_backtest.py`。

### GARCH 指数波动率分析

`GARCH.py` 以指数收益为例，进行平稳性与波动聚集相关检验，拟合 GARCH(1,1)，分析参数及下一交易日条件波动率，并绘制收益与波动率图。该模块主要用于统计建模学习，不直接预测股价方向。

### Transformer 时序预测实验

`trans.py` 基于 PyTorch 构建 Transformer，使用上证指数历史行情，以过去 30 个交易日的六类特征预测后续三个交易日收益，并提供训练、评估和模型保存流程。目前为实验脚本，标准化、时序切分及最新预测窗口仍需进一步核验。

### OpenFE 自动特征工程实验

`test4.py` 构造股票历史收益、量价及均线特征，使用 OpenFE 搜索衍生特征，并导出 CSV 或 Feather 数据，用于探索自动特征工程在股票预测中的应用。

## 八、常用入口

以下为脚本使用示例，具体参数以各脚本配置及帮助信息为准。下载、通知及完整主流程会访问外部服务或更新记录，运行前需完成相应配置。

```powershell
# 下载或更新日线及基础数据缓存
python download.py

# 三套日线策略回测
python botton_year_backtest.py
python test_year_backtest.py
python turn_year_backtest.py

# HMM 近一年月度抽样回测，支持续跑
python hmm_year_backtest.py --resume

# HMM 小样本试跑
python hmm_year_backtest.py --max-stocks 10 --output-dir model_artifacts/hmm_demo

# 查看分时强弱评分与批量排名的参数
python fenshi_strength.py --help
python rank_fenshi_strength.py --help

# 使用已保存的 LightGBM 模型按指定日期推理
python predict.py 000001.SZ --date 20261014
```

报告通常保存在 `model_artifacts/对应策略_year_backtest/日期区间/`，HMM 目录还包含频率后缀。进入目录后，用浏览器打开 `report.html`，用表格软件打开 CSV 明细。

## 九、自动化校验与当前边界

仓库包含分钟数据处理、缓存覆盖、策略边界及回测时序等测试脚本。部分回测测试依赖本地行情样本，可按所需模块运行，例如：

```powershell
python -m unittest test_botton_year_backtest test_search_year_backtests test_hmm_year_backtest -v
```

本仓库用于个人研究与辅助决策。实验脚本、接口探测程序和教学示例不代表已完成生产验证的交易功能；当前股票池、历史状态、复权、成交约束及数据覆盖均可能影响研究结果。历史回测、理论最佳收益和模型预测不构成未来收益保证。
