# CODE1
2026年A股量化程序管理仓库
本文件使用Tushare数据库，但由于Tushare的历史分钟K线数据成本过高，本人无力承担，所以分钟K线数据暂时使用腾讯和新浪的免费接口替换，但该接口只支持4个交易日内的数据拉取。
本文件的初心是全自动化交易，但受限于交易接口的限制，目前只做了选股策略和部分策略的买卖点程序。
由于目前市场由量化主导，节奏风格变换非常快，市场会不断地出现新的模式，我平均3~6个月会更新一套更贴合当前市场的策略。
本文件一共有4套选股程序，全部是基于量价的短线策略，下面将分别介绍每一套程序。

lianghua1_search_botton.py：此程序回测效果最好，也是我今年使用最多的一组策略，此策略的核心思路是捕捉中长线呈现上涨趋势的股票，在经历短暂调整并重新开始上涨的拐点是该策略的核心捕捉特征。我做了最近一年的策略回测报告，回测统一计算此股票被筛选出来后10天内的理论最大上涨幅度，最佳收益率 = max（后续卖出收盘价 ÷ 买入开盘价 − 1）× 100%。回测结果在botton_year_backtest文件夹中

lianghua1_search_turn.py：此策略与botton策略大部分相同，不同点在于重点捕捉底部趋势强烈反转的信号，侧重点在于反转。回测结果在turn_year_backtest文件夹中。

lianghua1_search_test.py：此策略与上述两套策略不同，这是一套高风险的超短线策略，核心思想是做空中接力，捕捉有可能开启二波主升浪拉升的股票。回测结果在test_year_backtest文件夹中。

上述三条策略适用于成交量充沛的市场，由于下半年市场转跌，能够被策略选出的股票数量大幅减少，7，8，9，10月基本都是空仓状态。但是市场上短线赚钱机会却不断涌现，于是我做了chaoduan_1.py这个超短线选股策略，此策略的核心思想是捕捉底部有放量异动但还未大幅拉升的股票。但此策略目前缺乏长期的分钟K线数据，暂时无法回测。

除了选股策略，本文件中还有很多为了辅助完成全自动交易而创建的程序，如发送买卖点信息的邮件，网络爬虫实时爬取分时数据，复盘程序等。

基于Q-LIB的机器学习选股策略我也有所尝试，但由于模型调整得不够好，以及个人电脑很难胜任多参数模型的训练，目前暂时没有合适的机器学习选股策略。
